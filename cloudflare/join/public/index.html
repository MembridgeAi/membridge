Setting up your team

One moment.

You're in

Team is ready. Install MemBridge on each machine and it will start sharing context automatically.

  1. Install it:
    curl -fsSL https://membridge.app/install.sh | sh
  2. Open it:
    membridge dashboard
  3. Sign in with Continue with GitHub — the same account you just used. Not the email and password fields; you don't have a password.

Then add a project from the app, or run membridge team link inside a repo. Invite the rest of your team from the app once you're set up.
